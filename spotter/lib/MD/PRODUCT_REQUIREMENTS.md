# Spott MVP - Product Requirements

## Vision

Enable travelers to reduce travel costs by sharing empty seats and carrying parcels on trips they are already making.

## Core Value Proposition

### Travelers
Reduce trip costs through cost sharing.

### Passengers
Travel between cities at lower cost.

### Parcel Senders
Get same-day parcel delivery through verified travelers.

---

## User Roles

### Traveler
- Create trip
- Manage trip
- Accept/reject passengers
- Carry parcels
- Receive ratings

### Passenger
- Search trips
- Request seat
- Pay contribution
- Track trip
- Rate traveler

### Parcel Sender
- Create parcel request
- Select traveler
- Verify delivery via OTP

---

- Rentals
