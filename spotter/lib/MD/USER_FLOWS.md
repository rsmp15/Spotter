# Spott MVP User Flows

## Traveler Flow

Login
→ Verify Driver
→ Add Vehicle
→ Create Trip
→ Receive Requests
→ Accept Passenger
→ Start Trip
→ Complete Trip
→ Receive Rating

---

## Passenger Flow

Login
→ Search Trip
→ View Trip Details
→ Request Seat
→ Payment
→ Track Trip
→ Complete Trip
→ Rate Traveler

---

## Parcel Flow

Create Parcel
→ Upload Parcel Photo
→ Sender Declaration
→ Select Traveler
→ Traveler Accepts
→ Pickup OTP
→ Delivery OTP
→ Complete
