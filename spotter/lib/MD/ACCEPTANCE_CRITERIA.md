# MVP Acceptance Criteria

## Create Trip

Given verified traveler

When trip details are entered

Then trip becomes searchable

---

## Search Trip

Given active trips exist

When passenger searches

Then matching trips appear

---

## Book Seat

Given seats available

When passenger requests seat

Then traveler can accept/reject

---

## Parcel Delivery

Given parcel accepted

When delivery OTP matches

Then parcel marked delivered

---

## SOS

Given active trip

When SOS pressed

Then:
- Live location shared
- Emergency contact notified
- Support alerted
